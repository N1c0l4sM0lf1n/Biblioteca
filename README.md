1.- Preguntas de cierre
  1) Me permite separar responsabilidades facilmente y mantener el codigo ordenado
  2) Terminaria convirtiendose en un codigo desordenado y dificil de mantener
  3) En el modelo contiene las reglas que dirigen el programa mientras que el controlador actua como intermediario entre el modelo y la vista
  4) La dependencia es una relacion temporal y debil mientras que la asociacion es una relacion mucho mas fuerte y duradera
  5) Por que es una entidad del dominio con informacion propia
  6) La regla de que si un libro solo puede prestarse si esta disponible
  7) BibliotecaVista, ya que se encarga de mostrar todo al usuario
  8) El Modelo, ya que las clases Libro y Biblioteca se encargan del estado del libro y cuando ocurre el prestamo respectivamenre
  9) Crear una nueva carpeta y guardar las clases libro, usuario y prestamo
  10) Cambiar la vista de la consola por GUI, ya sea por JavaSwing o alguna otra herramienta que se enfoque en lo visual
  11) Podria modificar los datos dentro de Modelo sin permiso y se perderia el control del paquete
  12) Protege la integridad del sistema, Mantiene el control de las reglas y reduce la probabilidad de que aparezcan errores inesperados
